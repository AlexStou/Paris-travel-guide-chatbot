# Paris Travel Guide Chatbot

A multi-turn chatbot built with the OpenAI API (gpt-4o-mini) that answers
tourist questions about Paris landmarks while keeping conversation context.

## What it demonstrates
- Chat Completions API with system / user / assistant roles
- Maintaining conversation history across multiple turns
- Controlling output with temperature and max_tokens

## How to run
1. `pip install -r requirements.txt`
2. Set your API key: `export OPENAI_API_KEY="your-key"`
3. Open `notebook.ipynb` and run all cells

*Built as a guided project on DataCamp.*
